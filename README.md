To install the font, download the .otf file, and then drag it into the 'add fonts' section in your settings (for Windows - if you're on something else, then you're on your own). Then, find and download an app that supports custom fonts (I like Libre Office, but there are plenty of other options), and it should be there somewhere if you search for it.
The .sfd (??) file is for Fontforge, if you want to edit the font, and make it look nicer (because I've never used Fontforge today, nor any other kind of digital graphic design app, to there is much to be improved on).
There is a vague guide on how to use both the writing system and the font, although it could do with being improved. It also hasn't been proofread yet, so may be completely incomprehensible. Otherwise, look up 'linja pi kute mute' or 'sitelen musi' to find out more about the system behind the script.
(NB: I'm not really a learner (though I could certainly still improve), I just wanted to try making a writing system and font. Please don't assume that because I made a writing system for toki pona then I must think that the others are all wrong/bad/inadequate. I use toki pona and sitelen pona daily, and know at least somewhat what I'm doing. Thanks.)
